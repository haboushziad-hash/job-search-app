## Step 6 — Verify via the audit JSON

After EACH run, run this verification query:

```cmd
cd "%USERPROFILE%\Documents\JobSearchApp\audits\runs"
python -c "import json,os,glob,collections; latest=max(glob.glob('*audit.json'), key=os.path.getmtime); d=json.load(open(latest, 'r', encoding='utf-8')); roles=d.get('all_qualifying_roles',[])+d.get('near_miss_roles_for_audit',[]); s3_yes=[r for r in roles if r.get('stage3_score') is not None]; s3_err=[r for r in roles if 'stage3_error' in (r.get('stage3_application_strategy') or '')]; s3_with_summary=[r for r in s3_yes if r.get('summary')]; scores=collections.Counter(r.get('score') for r in d.get('all_qualifying_roles',[])); tier=d.get('pipeline_funnel', {}).get('tier_breakdown', {}); funnel=d.get('pipeline_funnel', {}).get('per_source_funnel', {}); cost=d.get('run_metadata', {}).get('cost_breakdown', {}); print(f'== PASS/FAIL =='); print(f'Stage 3 ran: {len(s3_yes)} (need >=40)'); print(f'Stage 3 errored: {len(s3_err)}'); print(f'Stage 3 with summary: {len(s3_with_summary)}/{len(s3_yes) if s3_yes else 0}'); print(f'Score distribution top 10: {scores.most_common(10)}'); print(f'Tier: {tier}'); print(f'Cost: ${cost.get(\"total_usd\", 0):.4f}'); print(f'By stage: {cost.get(\"by_stage\", {})}'); print(f'Per-source funnel populated: {bool(funnel)} ({len(funnel)} sources)')"
```

### Pass criteria (all 3 personas should hit these)

| Criterion | Threshold |

| Stage 3 errored | 0 |
| Stage 3 summary coverage | 100% |
| No score with >5 roles clustered (was 22 at 45 in Run 3) | spread should be wider after tier-label removal |
| Per-source funnel populated | dict with 5+ sources |
| Cost by-stage populated | non-zero values for stage1/stage2/stage3/embeddings |
| Tier breakdown | STRONG+GOOD ≥ Run 3's 35 (with $130K salary may shift slightly) |
