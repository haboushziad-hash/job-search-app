## Per-Persona Breakdown Structure

For each of Ziad / Zach / Ryan I'll capture:

### A. Profile Snapshot (sanity check)
- Headline (does it reflect resume?)
- Salary minimum (matches input?)
- Target functions / industries (reasonable?)
- Excluded title patterns (does it include "sales" / "engineer" / etc. as expected?)
- Keywords (count, top 5 by tier, any Tier 3 that should be Tier 1?)
- Location radius (Richmond/DC/etc. ranges intact?)

### B. Pipeline Funnel — top-line numbers
- Total scraped → after_hard_filters → qualifying_final
- Tier breakdown: STRONG / GOOD / MAYBE / STRETCH
- Comparison to Run 3 (Ziad baseline: 18/17/17/48)

### C. Per-Source Funnel (NEW — was missing in Run 3 audit)
For each of 14 scrapers, the breakdown:
- raw_scraped → after_dedup → after_hard_filters → after_liveness → qualifying_final

|---|---|---|---|---|---|---|

### D. Stage 3 Pass/Fail Criteria
- Stage 3 ran on N roles (need ≥40)
